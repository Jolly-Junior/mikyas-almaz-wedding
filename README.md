# Mikyas & Almaz Wedding Website

A modern, Apple-inspired glassmorphism one-page wedding invitation website.

## What’s included
- One-page site: `index.html`
- Styling: `styles.css`
- Countdown + simple interactions: `script.js`
- Local images: `assets/images/`
- Optional Figma handoff kit: `figma-kit/` (tokens, screenshots, images)

## Run locally
From this folder:

```bash
python3 -m http.server 8000
```

Then open:
`http://127.0.0.1:8000/`

## Customize
- Names / date: `index.html` + `script.js`
- Colors / glass look: `styles.css`
- Photos: replace files in `assets/images/` and keep the same filenames
