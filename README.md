# Mikyas & Almaz Wedding Website

A modern, Apple-inspired glassmorphism one-page wedding invitation website.

## Live site
- GitHub Pages: `https://jolly-junior.github.io/mikyas-almaz-wedding/`

## What’s included
- One-page site: `index.html`
- Styling: `styles.css`
- Countdown + simple interactions: `script.js`
- Local images: `assets/images/`
- Optional Figma handoff kit: `figma-kit/` (tokens, screenshots, images)

## Project structure
```text
.
├── index.html
├── styles.css
├── script.js
├── 404.html
├── site.webmanifest
├── robots.txt
├── sitemap.xml
├── assets/
│   └── images/
└── figma-kit/
```

## Run locally
From this folder:

```bash
python3 -m http.server 8000
```

Then open:
`http://127.0.0.1:8000/`

## Customize
- Names / date: `index.html` + `script.js`
- Colors / glass look: `styles.css`
- Photos: replace files in `assets/images/` and keep the same filenames

## Deployment
This repo is set up to be served directly from GitHub Pages as a static site.
