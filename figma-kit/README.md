# Figma Kit — Mikyas & Almaz (Option B)

This kit helps you recreate the website UI inside Figma.

## What’s inside
- `STYLE_GUIDE.md` — quick specs for typography, colors, glass cards, and components
- `tokens/design-tokens.json` — extracted CSS variables + key UI effects
- `screenshots/` — full-page screenshots
  - `desktop-1440x900.png`
  - `mobile-390x844.png`
- `assets/images/` — the photos used by the website (copied here for easy drag/drop)

## How to use in Figma (simple workflow)
1. Create a new Figma file with pages:
   - **Cover**
   - **Reference**
   - **Components**
   - **Screens**
2. Drag the images in `screenshots/` onto the **Screens** page.
3. Create **Color Styles** and **Text Styles** using `tokens/design-tokens.json`.
4. Build the key components (Card, Bottom Dock Nav, Timeline Row, Gallery Item).
5. Recreate the layout using Auto Layout, and use `assets/images/` for fills.
